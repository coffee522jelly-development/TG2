# Cortado - CAD-Style Multi-Layer Thumbnail Generator

Cortadoは、Webブラウザおよびデスクトップ上で完全オフライン動作する高度なサムネイルジェネレーターです。
Three.jsによる3Dグラフィックスと、2D Canvasによるテキストレンダリングを組み合わせた、CADスタイルの独自のレイヤー編集体験を提供します。
「大人」「シック」「モダン」「クレバー」「スマート」をテーマにしたデザインに特化しています。

## 主な機能

*   **ハイブリッドレンダリングエンジン:** Three.jsを用いた3Dシェイプ（円、四角、星、ラインなど）の描画と、Canvas APIを用いたテキストの描画をシームレスに統合。
*   **デザインプリセット機能:** 5つのカテゴリー（Corporate & Business, Tech & Innovation, Minimal & Chic, Lifestyle & Premium, Academic & Smart）に分類された、合計50種類のプロフェッショナルなデザインテンプレートを標準搭載。年号は自動で現在の西暦に更新されます。
*   **キャンバスサイズ・アスペクト比選択:** 16:9 (YouTube), 1:1 (Instagram), 3:2, 2:3, 4:5 など、よく使われるSNS用のアスペクト比をプリセットから瞬時に切り替え可能。
*   **レイヤー管理:** テキストレイヤーとグラフィック（3D）レイヤーを個別に管理。前面/背面のZ軸（奥行き）調整も可能。
*   **完全オフライン動作:** Tauriを用いたデスクトップアプリとしてビルド可能であり、必要なWebフォントやアセットはすべてローカルにバンドルされているため、ネットワーク環境がなくても動作します。
*   **テキスト編集:** 美しいセリフ体やサンセリフ体など、洗練されたローカルフォントを使用してテキストを配置。
*   **エクスポート機能:** 作成した画像をWebPまたはPNG形式でローカルにダウンロード。

## 使い方

1.  `index.html`をWebブラウザで開くか、ビルドされたデスクトップアプリを起動します。
2.  左側のパネルの **[00] DESIGN PRESETS** から、用途に合わせたカテゴリー内のテンプレートを選択します。
3.  **[01] CANVAS PROPERTIES** で「SIZE PRESETS」から目的のアスペクト比を選択するか、手動でサイズを入力します。
4.  **[02] TEXT LAYERS** でテキストの追加や内容・フォントの編集を行います。
5.  **[03] GRAPHIC LAYERS (3D)** で図形の追加やサイズ・色の変更を行います。
6.  キャンバス上の文字や図形を直接ドラッグして配置を微調整します。
7.  完成したら **[04] EXPORT PIPELINE** からファイル名を入力し、「WEBP」または「PNG」ボタンを押して画像を書き出します。

## 開発環境

*   HTML5 / Canvas API
*   JavaScript (ES6+)
*   [Three.js](https://threejs.org/) (3D描画・ローカルバンドル)
*   [Tailwind CSS](https://tailwindcss.com/) (UIスタイリング・ローカルビルド)
*   [Tauri](https://tauri.app/) (デスクトップアプリ化)
